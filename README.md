# ☁️ Dream Cafe

Dream Cafe is a modern and aesthetic food website with a soft luxury theme. It provides a simple and attractive interface for users to explore menu items and special food offers.

## Features

✨ Soft luxury UI design  
✨ Responsive design for mobile and desktop  
✨ Sticky navigation bar  
✨ Smooth page transitions  
✨ Interactive menu page  
✨ Food cards with images and offers  
✨ Hover animations  
✨ Clean and modern layout  

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
